// FIELD MANUAL — 09 TRICKS

Every site has
a feed. Most just
hide it well.

A working list of URL tricks to turn almost any site into an RSS feed — Google News searches, Substacks, subreddits, YouTube channels, GitHub releases, newsletters. Copy-paste any of these into the + SOURCE field and you're subscribed.

01 / GOOGLE NEWS

Any search becomes a feed.

Insert /rss after the TLD in any Google News search URL.

news.google.com/rss/search?q=site%3Areuters.com&hl=en
02 / SUBSTACK

/feed at the root.

Every Substack publication exposes its feed at /feed.

stratechery.com/feed
03 / REDDIT

Any subreddit, any user.

Append .rss to any subreddit or user URL.

reddit.com/r/programming.rss reddit.com/r/worldnews.rss
04 / YOUTUBE

The hidden Atom feed.

Every channel has one. Grab the channel ID and use:

youtube.com/feeds/videos.xml?channel_id=…
05 / MEDIUM

Users and publications.

Prefix the path with /feed on medium.com.

medium.com/feed/@username medium.com/feed/publication-name
06 / WORDPRESS

The original RSS.

Nearly every WordPress site exposes a feed at /feed.

example.com/feed
07 / GITHUB

Releases, commits, tags.

Atom feeds, no auth required. Three flavors per repo.

github.com/owner/repo/releases.atom github.com/owner/repo/commits.atom
08 / NEWSLETTERS

Kill the Newsletter.

Generates a unique inbox; subscribe with it, get the feed.

kill-the-newsletter.com ↗
